# coolcoffeshop — Contexto del Proyecto

## Descripción

Landing page mobile-first responsive para una cafetería ficticia llamada **coolcoffeshop**. Proyecto diseñado para portfolio personal, enfocándose en estética, vibes y fluidez de interacción.

---

## Identidad de Marca

| Aspecto | Definición |
|---------|-------------|
| **Vibe** | Acogedor > Retro > Rústico (mínimo) |
| **Estilo visual** | Ilustrativo-abstracto, orgánico, "que se sienta" |
| **Interacciones** | Super animadas, clean, micro-interacciones,fluidas. La falta de utilidad real se compensa con un manejo gustoso y fluido de la UI |

### Direcciones de Ilustración

- **Estilo mixto**: Ilustración orgánica a mano + elementos geométricos abstractos
- **Textures**: Papel/cartón texturizado, grain sutil, bordes deshilachados
- **Shapes**: Bordes redondeados, formas suaves, ningún sharp edge
- **Iconografía**: Lineal, trazo desprolijo/hand-drawn, relleno sólido en verdes/mustard

### Fotografía / Imágenes

- Borde blanco tipo polaroid (2-4px)
- Ligero grano/vintage filter en fotos
-物的 warm tones, evitar whites puros
- Composición: espacios negativos generosos, elementos descentrados

### UI Components

| Componente | Estilo |
|------------|--------|
| **Botones** | Redondeados, shadow suave, hover en rosa dusty |
| **Cards** | Fondo crema, borde sutil verde, efecto papel |
| **Formularios** | Sin bordes, solo underline, labels flotantes |
| **Navegación** | Hamburger en móvil, menú minimal con tracking suave |
| **Scroll** | Smooth scroll, sticky headers con blur |

## Notas para desarrollo futuro

- Mobile-first: diseñar primero para móvil, luego desktop
- Micro-interacciones en hover, scroll, botones
- Transiciones suaves entre secciones
- Considerar animaciones sutiles (elementos flotando, fade-ins)
- Imagen de marca coherente: coherencia entre colores, tipografía e ilustración
